# 公図照合 | FIELD ALIGN

公図（PDF・画像）や法務省の登記所備付地図データ（地図XML）を、国土地理院の航空写真に重ねて照合する静的Webアプリです。

- アプリ本体：`docs/`（ビルド不要。GitHub Pages で `docs/` をそのまま配信）
- 更新メモ：`notes/`

## 主な機能

- 公図PDF・画像の読み込み、2点の目印による位置合わせ、対象地の座標取得、端末内の照合履歴
- G空間情報センターの登記所備付地図データ（ZIP・XML）の読み込み
  - 公共座標の図面はそのまま表示
  - 任意座標の図面は目印（1点〜複数点、最小二乗）で航空写真に位置合わせ
  - 地番検索、位置合わせ結果の端末内保存、GeoJSON出力

## データの扱い

読み込んだ公図・地図データ・照合履歴は、利用者のブラウザ内（IndexedDB）にだけ保存されます。このリポジトリやサーバーには送信されません。

任意座標の図面の位置は目印による推定です。筆界の確定や測量の代わりにはなりません。

## ローカルで動かす

```
python3 -m http.server 8080 --directory docs
```

`http://localhost:8080/` を開く（`file://` では動きません）。

## 使用ライブラリ・データ

- [Leaflet](https://leafletjs.com/) 1.9.4（BSD-2-Clause）
- [PDF.js](https://mozilla.github.io/pdf.js/) 4.10.38（Apache-2.0）
- 地図タイル：[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)
- 登記所備付地図データ：法務省（G空間情報センター経由で公開）
