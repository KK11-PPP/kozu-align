位置合わせ

図面上の道路の角などをタップし、続けて航空写真の同じ場所をタップします。1点で移動、2点で回転・縮尺、3点以上で誤差を計算します。

現在の機能と精度について

自動調整は、指定した2組の目印を使った位置・回転・縮尺の計算です。画像から場所を自動探索する機能は未実装です。公図のゆがみや境界の誤差は補正しきれません。結果は推定位置です。

保存先はこのブラウザです。別端末では出力データを保管してください。既存アプリへの取り込みは今後の対応です。出力には公図画像・配置情報・対象座標が含まれます。

登記所備付地図データのうち「任意座標」の図面は、目印による推定位置です。旧公図はゆがみがあるため、図郭（1枚）ごとに合わせると精度が上がります。筆界の確定や測量の代わりにはなりません。
